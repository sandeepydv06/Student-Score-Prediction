# 📊 Student Score Prediction using Machine Learning

## 📌 Project Overview

This project predicts a student's exam score based on study hours using the Linear Regression algorithm. The project demonstrates the complete Machine Learning workflow, including data preprocessing, visualization, model training, prediction, evaluation, and model deployment.

---

## 🎯 Objective

To build a Machine Learning model that predicts student scores based on the number of study hours.

---

## 🛠 Technologies Used

- Python
- NumPy
- Pandas
- Matplotlib
- Scikit-learn
- Joblib
- Jupyter Notebook

---

## 📂 Dataset

The dataset contains:

- Study_Hours
- Attendance_Percent
- Sleep_Hours
- Practice_Tests
- Score

Target Variable:
- Score
